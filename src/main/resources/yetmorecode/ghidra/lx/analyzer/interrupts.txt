# Names of interrupt functions for the interrupt annotator.
#
# Format (fields separated by spaces, the rest of the line is the name):
#   <interrupt hex> *         <name of the interrupt>
#   <interrupt hex> AH=<hh>   <name of the function>   (function identified by AH only)
#   <interrupt hex> AX=<hhhh> <name of the function>   (function identified by AX, takes precedence over AH)
#
# Only add verified entries. Sources: general DOS/DPMI/VESA functions from the usual references,
# DOS/32A functions and names from the DOS/32A documentation (Programmer's Reference).
# Unknown functions (e.g. INT 21h AH=ED, INT 2Fh AX=FA1F) are neither documented there nor in the source
# code of DOS/32A and are therefore not named.
